## 🎯 How It Works (Simple Explanation)

Your computer has a built-in power management system that tells it to sleep when you stop using it. This saves energy but can be annoying when you actually need the screen to stay on.

Caffeine works by sending a tiny signal to Windows that mimics user activity. It tells Windows, "Hey, the user is still here — don't sleep." But it doesn't actually move your mouse or type anything. It's completely subtle and doesn't interfere with what you're doing.

The best part: it only does this while you have it activated. When you turn it off, your PC returns to its normal sleep schedule.

## 🔧 Troubleshooting

**I don't see the coffee cup icon in my tray**
- Click the small arrow (^) at the bottom-right of your screen to see hidden icons
- If it's still not there, try running the program again
- Check that the file was fully downloaded and wasn't blocked by your antivirus

**Windows says "Unknown Publisher"**
- This is normal. Click "More info" → "Run anyway"
- The program is safe and has no malware

**My PC still sleeps even with Caffeine on**
- Make sure you actually clicked the cup to turn it on (the icon should look active)
- Some special power settings (like "hibernate after" in advanced settings) might still trigger. Try clicking the cup off and on again.

**The program doesn't run automatically at startup**
- Right-click the coffee cup icon in the tray
- Look for an option that says "Start with Windows" or "Launch at startup"
- Make sure it's checked

**I accidentally closed it**
- Just run the .exe file again. It will reopen instantly.
